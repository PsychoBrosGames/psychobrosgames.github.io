Quick verdict

Starfighter spectacle built for another run.

Rogue Eclipse understands that a space roguelike needs more than upgrade menus: the flying itself has to feel dangerous and fast. Destructible environments and behemoth-scale enemies give its run structure a strong visual purpose, while its Arabesque Futurism helps it avoid generic military sci-fi.

What it is

The player is a pilot fighting for humanity's future through repeated arcade-style spaceflight runs. Ships can be upgraded as battles escalate from fighter skirmishes to encounters with enormous enemy machines.

Destructible environments broaden the combat space, while a visual direction inspired by Arabesque Futurism gives the ships and world a recognizable identity. The target is speed and spectacle without surrendering the build decisions expected from a roguelike.

What stands out

  • Arcade starfighter controls are paired with a repeated roguelike run structure.
  • Battlefields include destructible environments and enemy behemoths.
  • The visual world draws on Arabesque Futurism.

The three-player read

One game. Three save files.

01

The Casual

The flight model decides who gets invited.

Speed is exciting only if orientation stays readable. Strong aim assistance and clear objectives would make the spectacle accessible without flattening the challenge.

02

The Tactician

Destruction should create choices, not only particles.

Environmental damage is most valuable when it changes routes, exposes weak points, or creates cover. Ship upgrades need the same tactical specificity.

03

The All-Rounder

A clean run length could make this rotation-ready.

Space combat and obvious boss scale are easy to return to. The question is whether progression respects players who want a satisfying session without committing an entire night.

Who this game fits

Best for

  • Starfighter fans who want arcade speed over simulation
  • Roguelike players drawn to visible build progression
  • Anyone looking for science fiction outside familiar military aesthetics

Watch for

  • Spatial readability at high speed
  • Upgrade variety across repeated runs
  • Whether destruction changes tactics or remains mostly visual
